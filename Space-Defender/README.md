## About the Game

Space Defender is a 2D space-shooter game developed using Python and Pygame. The player controls a spaceship and shoots incoming enemies to earn points while trying to survive.

## How to Play

| Key | Action |
|---|---|
| Left Arrow | Move the spaceship left |
| Right Arrow | Move the spaceship right |
| Spacebar | Shoot bullets |
| R | Restart the game after game over |
| Esc | Quit the game |

## Features

- Graphical game window using Pygame
- Keyboard-controlled spaceship
- Moving enemy spaceships
- Shooting mechanics
- Collision detection between bullets and enemies
- Collision detection between enemies and the player
- Score displayed on the screen
- Game-over screen showing the final score
- Restart and quit options

## Technologies Used

- Python
- Pygame

## Installation and Setup

1. Install Python on your computer.
2. Install Pygame using the following command:

   ```bash
   python -m pip install pygame
   ```

3. Clone this repository:

   ```bash
   git clone https://github.com/MD-Rasheduzzaman-3852/Space-Defender.git
   ```

4. Open the project folder:

   ```bash
   cd Space-Defender
   ```

5. Run the game:

   ```bash
   python main.py
   ```
